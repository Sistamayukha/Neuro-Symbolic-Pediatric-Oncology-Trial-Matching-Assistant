# Osteosarcoma trial dataset — next step

These files were derived from the team-provided ClinicalTrials.gov export enriched with eligibility text.

- `all_30_trials.csv`: Full 30-trial RAG candidate corpus.
- `reviewed_shortlist_10.csv`: Human-readable preliminary prioritization, including full trial eligibility text.
- `five_proposed_trials.csv`: Five proposed MVP trials for initial team review.

These selections are an engineering shortlist, not clinically verified eligibility rules or a guarantee of current recruitment status. Review exact inclusion/exclusion criteria and study-specific arms and cohorts in original registry pages before coding. Preserve text as evidence; do not convert criteria blindly to numerical rules.
